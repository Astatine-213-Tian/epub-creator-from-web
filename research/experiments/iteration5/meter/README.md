# Content-Resistant Style Meter

The CR-FYSM development chain asks whether target-author style can be measured
without rewarding book content. Files are chronological: preregister a version,
build or rescore it, analyze it, then challenge it on external authors. The
`v1`-`v4` suffixes identify successive measurement repairs.

Start with `benchmark_content_resistant_meter.py` for the shared benchmark
surface, then read `build_cr_fysm_v3.py`, `develop_cr_fysm_v4.py`, and the v4
preregistration/rescoring files for the final chain. External confirmation is
handled by `preregister_external_author_*` and `score_external_author_v2.py`.

The final result is negative: CR-FYSM-v4 is retained as diagnostic evidence but
is not the production transfer-selection endpoint.
